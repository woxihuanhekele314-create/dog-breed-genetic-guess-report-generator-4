# 犬种基因猜测报告生成器

一个根据单只狗狗照片，生成简体中文竖版《犬种基因猜测报告》的 Skill。

## 主要功能

- 检查照片是否清晰
- 判断照片中是否只有一只狗狗
- 询问并使用狗狗名字
- 根据外观特征推测可能的犬种组成
- 生成简体中文犬种猜测报告
- 按照固定版式输出竖版图片
- 对最终成图进行内容和版式审核

## 使用方法

1. 下载本仓库文件。
2. 保持文件结构完整。
3. 将整个文件夹压缩为 ZIP。
4. 将 ZIP 上传至支持 Skills 的环境中。
5. 上传一张清晰的单只狗狗照片。
6. 提供狗狗名字。
7. 根据流程生成报告。

详细说明请参阅《安装与使用.md》。
