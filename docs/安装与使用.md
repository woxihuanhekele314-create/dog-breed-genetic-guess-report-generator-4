# 安装与使用

## ChatGPT Skills 页面

1. 打开 ChatGPT 的 Skills 页面。
2. 选择 Create / 创建。
3. 选择从电脑上传。
4. 上传本压缩包 `dog-breed-genetic-guess-report-generator.zip`。
5. 安装后，上传一张狗狗照片测试自动触发。

## 通过 Skill Creator

打开“可复制到Skill Creator的配置文本.md”，复制全部内容，粘贴到 Skill Creator 中创建。

## 测试建议

先使用一张：

- 只有一只狗
- 面部清晰
- 耳朵、口吻、毛色可见
- 最好能看到部分身体轮廓

的照片测试。

测试时，Skill 应先询问狗狗名字，随后生成一张 1080 × 1920 PNG 长图。
