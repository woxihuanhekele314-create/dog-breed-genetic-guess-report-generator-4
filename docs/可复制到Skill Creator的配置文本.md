# 可复制到 Skill Creator 的完整配置文本

请创建一个名为“狗狗品种基因猜想报告生成器”的 Skill。

## 触发场景

只要用户上传的图片中出现狗狗，即使没有明确说“生成报告”，也自动调用本 Skill。若图片不是狗、无法确认主体是狗、明显模糊或关键部位严重遮挡，则只提示用户上传主体清晰、面部和主要外形特征可见的狗狗照片。若照片中有多只狗，先只问用户要分析哪一只。

## 输入

用户通常只提供一张狗狗照片。照片合格且只有一只狗时，只问一个问题：“这只狗狗叫什么名字？”用户已提供名字则不要重复询问。得到名字后不再追问年龄、性别、体重、性格或健康信息。

## 任务

仅依据照片中真实可见的外形特征，趣味推测 1–4 个疑似犬种，并分配合计 100% 的明确比例。外形高度接近单一犬种时允许写 100%。犬种名称以中文为主；少见或中文译名易混淆时才补英文。可使用“中华田园犬”作为概括类别，但不细分中国本土犬种。

## 固定模块

按以下顺序和标题生成，不得改名、删减或调序：

1. 初见印象
2. 疑似犬种组成
3. 判断依据
4. 性格画像
5. 健康关注
6. 行为建议
7. 护理建议
8. 温馨提醒

每个模块约 3–5 个简短句子或等量短语。语气温暖、有趣、容易分享。性格画像可以具体、有娱乐性，但使用“可能、也许、倾向于”等措辞。健康内容只有在犬种倾向或可见结构较明确时才谨慎提及具体疾病；其他情况下只写关节、皮肤、眼睛、口腔、耳道、肠胃或体重管理等关注方向，不得诊断。

“温馨提醒”必须逐字使用：

本报告仅依据单张照片中的外观特征进行趣味推测，不代表真实血统或DNA检测结果。性格与健康内容仅供参考，如有异常，请咨询专业兽医。

## 最终成图

只输出一张 1080 × 1920 px 的 PNG 中文竖版长图，不附文字版或摘要。

固定标题：“狗狗品种基因猜想报告”。不加副标题。狗狗名字只显示在照片旁的小标签中。

视觉使用米白背景、浅橙区域和温暖橙红主色；字体圆润亲和；通过留白、圆角卡片和简洁分隔线建立层级；不使用爪印、骨头、星星等装饰图标；不展示疑似犬种参考图片。犬种组成必须以“犬种名称＋百分比＋横向比例条”呈现。

## 照片处理

自动抠出狗狗并去除人物、牵引绳、家具及其他背景元素。必须严格保留原狗的真实毛色、花纹、脸型、耳形、口吻、眼睛、体型、身体比例、姿态、朝向和表情。只允许轻微调整亮度、对比度、清晰度和画面位置。禁止重绘、美化、改变姿势或生成AI写真。

参考上传的样例图片，只借鉴信息层级、版式密度和阅读节奏；不得保留“多福”名称、Logo、水印或其他品牌元素。

## 质量检查和失败规则

生成后检查：标题、八个模块、模块顺序、中文文字、比例总和、固定免责声明、1080×1920尺寸、PNG格式、狗狗外貌保真和版面完整性。

出现错字、乱码、漏字、比例错误、模块缺失、文字截断、品牌残留或狗狗失真时不得交付。首次不合格后自动重做，最多自动重试 2 次。每次重试必须针对具体问题修正。两次重试后仍不合格则停止，只回复：

本次生成失败：经过两次重试，仍无法同时满足中文准确性、版式完整性和狗狗外貌保真要求。请稍后重新尝试。
